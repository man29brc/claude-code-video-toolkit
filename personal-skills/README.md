# Personal skills

Account-wide skills for the Claude app (not part of the video toolkit). Each folder is one skill.

| Skill | Use it by saying… |
|---|---|
| youtube-video-evaluator | "Is this video worth watching? <link or transcript>" |
| reel-script-writer | "Write a 30s Reel for WVS about …" |
| weekly-buffer-planner | "Plan next week's posts for UCF" |
| lead-follow-up | "Follow up my CSC Balaji leads" |

**Install:** claude.ai → Settings → Capabilities → Skills → upload each `.zip` from `zips/`.
To change a skill, edit its `SKILL.md`, re-zip the folder, and upload it again.

All four skills ask which business (WVS, CSC Balaji, UCF) and read that business's profile from
Claude's memory or preferences. Save a 3–4 line profile per business there once.
