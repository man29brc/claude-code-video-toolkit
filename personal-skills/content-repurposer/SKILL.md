# Content Repurposer

One idea, many formats: this gets the most out of every shoot or event.

## 1. Input

Accept whatever the user has: a pasted transcript or script, a caption, notes, a voice-note transcript, a video description, an event summary, or a description of photos. If you only have a link you can't open, ask them to paste the text or transcript.

Ask **which business** (WVS, CSC Balaji, UCF) if it isn't clear, and load its profile (tone, language, CTA) from memory or preferences.

## 2. Extract first

Pull out, briefly:
- **Core message** (one sentence)
- **3–7 standalone points**: tips, facts, moments, quotes
- **Best hook moment** (the most surprising or emotional line)
- **Proof**: any result, number, or story (only what's actually in the source)

## 3. Produce the pack

Only include formats that fit the source. Skip the rest and say why.

```
## Repurpose pack · <Business> · from "<source title>"

### 1. Reels / Shorts (1–3)
Each: hook (first 2s) · 3–5 timed beats · on-screen text · where to cut from the source (timestamp if known) or what to film.

### 2. Instagram carousel (5–8 slides)
Slide 1 hook · one point per slide (≤20 words) · last slide CTA. (Offer to design it: instagram-carousel skill.)

### 3. Feed post caption
Hook line · 3–5 short lines · CTA · 5–8 hashtags.

### 4. Stories (3–5 frames)
Frame-by-frame text + interactive sticker idea (poll/quiz/question/link).

### 5. WhatsApp
Status text (≤2 lines) + a WhatsApp Group post (≤5 lines, personal tone, clear CTA). No mass broadcasts: 1:1 messages only when personal.

### 6. Facebook post
Slightly longer, conversational, local-community tone.

### 7. YouTube Shorts
Title (≤60 chars) + 2-line description.
```

## Rules
- **WVS content** (mutual funds / insurance): run the **finance-compliance-checker** skill before it's published or scheduled.
- Don't suggest upselling PAN customers into home loans, or using the CSC shop counter for marketing.
- **No health insurance content** (posts, reels, ads). It's sold only via CSC Balaji when customers ask.
- Each format must work **on its own**. Don't write "as seen in our Reel".
- Vary the hook across formats. Don't paste the same first line everywhere.
- Match the language to the audience (English, Hindi, Hinglish, or regional), as the profile says. Ask if unsure.
- Never add facts, numbers, or claims that aren't in the source or the profile. Use `[placeholder]`.
- UCF: respectful, consent-aware use of beneficiaries' stories and images.
- End by offering to schedule the pack (weekly-social-planner).
